# Урок 20 — JSON

Шпаргалка для лайв-кодинга. Теория, тайминг и практика — в `Urok_19_JSON.md`.

## Главные аналогии (сказать в начале)
- JSON — **общий язык программ**. Go, JavaScript и Swift не понимают структуры друг друга, но все понимают JSON.
- `Marshal` — **упаковать чемодан** (структура Go → JSON-текст). `Unmarshal` — **распаковать** (JSON → структура).
- Тег `json:"name"` — **переводчик**: в Go поле `Name`, в JSON — `name`.
- HTTP-запрос — **заказ в ресторане**: отправили запрос → пришёл ответ (Response) → ответ — это JSON → распаковали в структуру.

## Типы: Go ↔ JSON
| Go | JSON |
|---|---|
| `string` | string |
| `int`, `float64` | number |
| `bool` | boolean |
| срез `[]T` | array `[...]` |
| структура, `map` | object `{...}` |
| `nil` | `null` |

## Sandbox: JSON по сети (`sandbox-json/`)
Нужен интернет. Используем бесплатный тестовый API `jsonplaceholder.typicode.com`.
Идея: до этого JSON был строкой в коде. Теперь он **приходит с настоящего сервера**.

| # | Папка | Что показываем |
|---|---|---|
| 1 | `01-http-get-tekst` | `http.Get`, `resp.Body`, `defer Close`. Смотрим сырой JSON. |
| 2 | `02-json-v-strukturu` | `Unmarshal` ответа в структуру. Лишние поля пропускаются. |
| 3 | `03-spisok-iz-api` | Массив → `[]Todo`. `json.NewDecoder(resp.Body)`. |
| 4 | `04-vlozhennyj-json` | Вложенный JSON (address → geo, company). |
| 5 | `05-post-zapros` | `http.Post`: отправляем JSON, получаем JSON обратно. |
| 6 | `06-oshibki-i-status` | Три уровня проверки: `err`, `StatusCode`, ошибка разбора. Таймаут. |

Схема, которую нарисовать на доске:
```
Наша программа ──GET──▶ Сервер
                ◀─JSON── Сервер
   │
   └─ Unmarshal → структура Go → работаем с ней как обычно
```

**Что сказать про `net/http`:** «Пока просто пользуемся — как `fmt.Println`. Свой сервер будем писать на следующем уроке».
**Если нет интернета:** шаги 01–11 работают офлайн. Для sandbox можно показать вывод заранее.

## Частые ошибки новичков
| Ошибка | Симптом | Решение |
|---|---|---|
| Поля с маленькой буквы | Пустой `{}`, ошибки нет | Заглавная буква |
| Забыт `&` в `Unmarshal` | `Unmarshal(non-pointer ...)` | Передать `&u` |
| Пробел в теге `json: "name"` | Тег молча не работает | `json:"name"` без пробела |
| `.(int)` для числа из `any` | panic | Приводить к `float64` |
| Не проверена ошибка | Пустые данные без объяснений | Всегда `if err != nil` |
| `omitempty` для нужного `0` | Поле пропало | Указатель `*int` |
| Не закрыт `resp.Body` | Утечка соединений | `defer resp.Body.Close()` |
| Не проверен `StatusCode` | Разбор пустого/ошибочного ответа | `resp.StatusCode != 200` |
