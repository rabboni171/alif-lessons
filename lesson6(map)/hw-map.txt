Домашнее задание: map

1. Через литерал создай map[string]int с оценками 4 учеников. Выведи всю map, а также оценку одного конкретного ученика.

2. Создай пустую map[string]float64 через make. Добавь в неё через присваивание цены 4 товаров. Выведи map и её len.

3. Дана map с ценами товаров. Через comma-ok проверь, есть ли в ней товар "сыр": если есть — выведи цену, если нет — выведи "такого товара нет".

4. Дана map с возрастами друзей. У одного из друзей сегодня день рождения — увеличь его возраст на 1 прямо в map (без создания новой переменной) и выведи результат.

5. Дана map с товарами и их остатком на складе. Удали через delete товар, который закончился, а затем через comma-ok убедись, что его больше нет в map.

6. Создай пустую map[string]int. Через оператор ++ поставь 3 «лайка» одному видео и 2 «лайка» другому — просто обращайся к нужному ключу несколько раз подряд (без предварительной проверки наличия ключа). Выведи получившуюся map.

7. Дана map с оценками учеников. Через for range выведи все пары "ученик: оценка". Отдельным циклом выведи только имена учеников (без оценок).

8. Та же map с оценками — выведи её содержимое в отсортированном по имени ученика порядке (собери ключи в срез, отсортируй через sort.Strings).

9. Дан срез посетителей сайта (некоторые повторяются). Через map[string]bool построй множество уникальных посетителей и выведи их количество.

10. Дана map[string][]string "группа -> список студентов". Добавь нового студента в одну из групп через append и выведи обновлённую map.

11. Дана map с зарплатами сотрудников (map[string]int). Через range и if найди сотрудника с максимальной зарплатой и выведи его имя вместе с зарплатой.

12  Дан текст (строка-предложение). Раздели его на слова через strings.Fields, посчитай частоту каждого слова через map, выведи слова в отсортированном по алфавиту порядке вместе с количеством повторов, и дополнительно найди самое частое слово.

13. Дан срез с названиями городов (некоторые повторяются). Посчитай, сколько раз встречается каждый город, используя map[string]int и оператор ++ (без предварительной проверки наличия ключа).
