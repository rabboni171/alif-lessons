Домашнее задание: горутины (go func()) и sync.WaitGroup

Горутины: запуск и главная проблема

1. Напиши функцию printSlowly(name string): печатает "Начали: <name>", ждёт time.Sleep(1 * time.Second), печатает "Готово: <name>". Вызови её три раза подряд обычным способом (без go) и выведи, сколько всего заняло времени (time.Now() / time.Since()).

2. Возьми функцию из задания 1 и запусти те же три вызова через go printSlowly(...), больше ничего не меняя. Запусти программу несколько раз. Комментарием в коде коротко напиши, что видишь в выводе (печатается ли вообще что-то и почему).

3. Почини задание 2 "костылём": в конце main добавь один time.Sleep(2 * time.Second), чтобы горутины успели закончиться. Комментарием напиши одно предложение — в чём минус такого способа ждать горутины.

Sync.WaitGroup: Add, Done, Wait

4. Перепиши задание 3 без time.Sleep в main — с помощью sync.WaitGroup: заведи var wg sync.WaitGroup; перед каждым go printSlowly(...) вызови wg.Add(1); передай &wg в функцию; внутри функции первой строкой поставь defer wg.Done(); в конце main вызови wg.Wait().

5. Напиши функцию greet(name string, wg *sync.WaitGroup), которая через defer wg.Done() печатает "Привет, <name>!" после time.Sleep(300 * time.Millisecond). В main заведи срез из 5 имён и в цикле запусти горутину для каждого имени (не забудь Add и Wait).

6. Напиши функцию countTo(n int, wg *sync.WaitGroup), печатающую числа от 1 до n с паузой 10 * time.Millisecond между ними. Запусти как горутины countTo(5, ...), countTo(3, ...), countTo(7, ...) и дождись всех через WaitGroup.

Анонимные горутины

7. Перепиши задание 6 без отдельных функций — используй анонимную горутину прямо в main: go func(n int) { defer wg.Done(); ... }(5) и так же для 3 и 7.

8. Заведи for i := 1; i <= 8; i++ и в цикле запускай анонимную горутину, которая получает номер как аргумент (go func(id int) {...}(i)), спит time.Duration(id) * 50 * time.Millisecond и печатает "Горутина <id> завершена". Дождись всех через WaitGroup.

9. К заданию 8 добавь: перед циклом с горутинами сделай то же самое (8 пауз) обычным циклом, без go. Выведи оба времени — обычное и с горутинами — рядом друг с другом.

Порядок выполнения и рантайм горутин

10. Напиши программу с 10 горутинами, каждая печатает свой номер от 1 до 10 (fmt.Print). Дождись через WaitGroup. Запусти программу 3 раза подряд и сравни вывод — порядок чисел должен быть разным.

11. Используй runtime.NumGoroutine(): напечатай его один раз до запуска 50 горутин (каждая просто спит 100 * time.Millisecond), один раз сразу после запуска всех (до wg.Wait()), и один раз после wg.Wait().

12. Запусти 100_000 горутин, каждая из которых делает только time.Sleep(1 * time.Millisecond). Дождись всех через WaitGroup и выведи, сколько заняло времени всего.

Гонка данных (просто увидеть проблему, без мьютекса)

13. Заведи переменную counter := 0 и запусти 1000 горутин, каждая делает counter++ (без всякой защиты, только WaitGroup). Выведи итоговое значение counter — запусти программу несколько раз и убедись, что число каждый раз разное и почти никогда не равно 1000.

14. Запусти программу из задания 13 командой go run -race . и скопируй в комментарий рядом с кодом первую строку предупреждения, которую покажет терминал (там будет DATA RACE).

15. Возьми задание 13, но вместо одной общей переменной counter заведи results := make([]int, 1000). Пусть горутина номер i делает results[i] = 1 (только свою ячейку, не общую переменную). После wg.Wait() посчитай сумму среза обычным циклом. Убедись, что теперь результат всегда ровно 1000.

Задачи среднего уровня

16. Дан срез из 5 имён файлов. Функция download(name string, wg *sync.WaitGroup) печатает "Скачали: <name>" после паузы 1 секунда. Запусти скачивание всех файлов одновременно через горутины и WaitGroup. Выведи время работы и сравни с тем, сколько заняло бы скачать файлы по одному (5 секунд).

17. Дан срез из 6 сайтов (строк). Заведи results := make([]string, len(sites)). Запусти горутину на каждый сайт: горутина номер i после небольшой паузы записывает results[i] = sites[i] + " - OK". Дождись всех через WaitGroup и в конце выведи results по порядку.

18. Дан срез из 10 чисел. Заведи doubled := make([]int, 10). Запусти горутину на каждое число: она умножает своё число на 2 и кладёт результат в doubled по тому же индексу (каждая горутина трогает только свою ячейку). После wg.Wait() выведи рядом исходный срез и doubled.

19. Дан срез из 5 "задач" (просто строки-названия). Функция runTask(name string, wg *sync.WaitGroup) печатает "Задача <name> началась" и "Задача <name> закончена" с паузой между ними. Запусти все задачи через горутины и одну WaitGroup, а после wg.Wait() выведи итоговое количество выполненных задач и общее время работы.

20. Собери из заданий 16-19 один мини-проект: список из 6 сайтов, функция проверки сайта с паузой, results по индексу (как в задании 17), запуск всех проверок горутинами с одной WaitGroup, вывод результатов по порядку и общего времени. Дополнительно выведи, сколько заняла бы такая же проверка по одному сайту за раз (сумма пауз), и сравни с реальным временем.

Что считается сделанным: используются только go func() / go имяФункции(...) и sync.WaitGroup — без sync.Mutex, sync.RWMutex и каналов (chan), это будет позже; wg.Add(1) вызывается до go, а не после; wg.Done() вызывается через defer первой строкой внутри горутины; sync.WaitGroup передаётся в функции только через указатель (*sync.WaitGroup); в заданиях 17-20 каждая горутина пишет только в свою ячейку среза, без пересечений с другими горутинами.
