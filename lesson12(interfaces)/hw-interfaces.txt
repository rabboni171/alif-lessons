Домашнее задание: интерфейсы, пустой интерфейс, type assertion

Базовые интерфейсы и полиморфизм

1. Опиши интерфейс `Vehicle` с методами `Start() string` и `Stop() string`. Типы `Car`, `Bike` и `Bus` (структуры с полем `Name` string) реализуют оба метода, возвращая что-то вроде "Car Toyota заводится" и "Car Toyota глохнет". Собери срез `[]Vehicle` из нескольких машин, велосипедов и автобусов и в цикле выведи для каждого сначала `Start()`, потом `Stop()`.

2. Интерфейс `Shape` с методами `Area() float64` и `Perimeter() float64`. Типы `Circle`, `Rectangle` и `Triangle` (площадь треугольника — по формуле Герона для сторон a, b, c) реализуют интерфейс. Дан срез `[]Shape` из 4-5 фигур разных типов — посчитай и выведи суммарную площадь всех фигур.

3. Интерфейс `Employee` с методами `Salary() float64` и `Position() string`. Структура `Manager` (`Name` string, `BaseSalary` float64) — `Salary()` возвращает `BaseSalary` плюс 20% бонуса. Структура `Developer` (`Name` string, `BaseSalary` float64, `Level` string) — `Salary()` возвращает `BaseSalary`, а для уровня "senior" добавляет ещё 30%. Дан срез `[]Employee` из нескольких менеджеров и разработчиков — найди и выведи сотрудника с самой высокой зарплатой.

4. Интерфейс `Instrument` с методом `Play() string`. Типы `Guitar`, `Piano` и `Drum` (структуры с полем `Name` string) реализуют его, возвращая что-то вроде "Guitar Fender: дзынь-дзынь". Собери срез `[]Instrument` — небольшой оркестр из 4-5 инструментов — и выведи, что играет каждый из них.

5. Интерфейс `Warrior` с методами `Attack() int` и `Description() string`. Структуры `Knight` (`Name` string, `Strength` int — `Attack()` = `Strength * 2`), `Archer` (`Name` string, `Precision` int — `Attack()` = `Precision + 10`) и `Mage` (`Name` string, `ManaPower` int — `Attack()` = `ManaPower * 3`). Собери срез `[]Warrior` из воинов разных типов, выведи `Description()` каждого и посчитай суммарную силу атаки всего отряда.

6. Интерфейс `Transport` с методом `Price(distanceKm float64) float64`. Типы `Taxi` (фиксированная посадка + цена за км), `Bus` (фиксированная цена независимо от расстояния) и `Bike` (только цена за км, подешевле такси) реализуют интерфейс по-своему. Для одного и того же расстояния посчитай стоимость поездки по каждому виду транспорта из среза `[]Transport` и выведи, какой вариант дешевле всего.

7. Интерфейс `Discount` с методом `Apply(price float64) float64`. Типы `PercentDiscount` (`Percent` float64) уменьшает цену на процент, `FixedDiscount` (`Amount` float64) вычитает фиксированную сумму, `NoDiscount` возвращает цену без изменений. Дан срез `[]Discount` из нескольких скидок — примени их к цене товара по очереди, одну за другой, и выведи итоговую цену после каждого шага.

Пустой интерфейс (any)

8. Напиши функцию `Describe(v any)`, которая печатает значение и его тип через `%v` и `%T`. Вызови её по очереди с int, string, float64, bool, срезом `[]int` и структурой `Point` (`X`, `Y` int) — посмотри, как меняется вывод `%T` в каждом случае.

9. Структура `Box` с единственным полем `Value any`. Создай срез из 5-6 `Box`, положив в `Value` разные по типу значения (число, строку, срез, структуру). В цикле выведи для каждого `Box` его содержимое и тип содержимого.

Type assertion

10. Напиши функцию `AsString(v any) (string, bool)`, которая через безопасное приведение типа (`v.(string)` с `, ok`) возвращает строку и `true`, если внутри `v` действительно строка, иначе — пустую строку и `false`. Проверь функцию на нескольких значениях разных типов, не вызывая панику ни на одном из них.

11. Дан срез `[]any`, где вперемешку лежат значения `Circle` и `Rectangle` из задачи 2 (они реализуют `Shape`), а также несколько чисел и строк "для шума". Через безопасное приведение к `Shape` (`v.(Shape)` с `, ok`) отбери только фигуры и посчитай суммарную площадь, не паникуя на остальных элементах.

Type switch

12. Напиши функцию `Classify(v any) string`, которая через `switch x := v.(type)` возвращает описание значения: для `int` — "целое число: N", для `float64` — "дробное число: N", для `string` — "строка длиной N символов", для `bool` — "логическое значение", для `nil` — "пусто", для остальных — "неизвестный тип: T". Вызови функцию на срезе `[]any` минимум из 6 значений и выведи результат для каждого.

13. Структура `Product` (`Name` string, `Price` float64) и интерфейс `Shape` из задачи 2. Напиши функцию `Process(v any)`, которая через `switch x := v.(type)` обрабатывает три случая: `Product` — печатает название и цену, `Shape` — печатает площадь, всё остальное — печатает "не знаю, что с этим делать". Вызови её на срезе `[]any`, где вперемешку лежат `Product`, фигуры и, например, число.

Композиция интерфейсов

14. Опиши интерфейсы `Flyer` с методом `Fly() string` и `Swimmer` с методом `Swim() string`. Собери из них интерфейс `Amphibious`, встроив оба. Структура `Duck` (`Name` string) реализует оба метода. Заведи переменную типа `Amphibious`, присвой ей значение `Duck` и вызови оба метода через эту переменную.

15. Опиши интерфейсы `Depositor` с методом `Deposit(amount float64) error` и `Withdrawer` с методом `Withdraw(amount float64) error`. Собери из них интерфейс `Account`, встроив оба. Структура `Wallet` (приватное поле `balance float64`) реализует оба метода с проверкой на отрицательную сумму и нехватку денег. Заведи переменную типа `Account`, присвой ей `*Wallet` и продемонстрируй пополнение и снятие через интерфейсную переменную.

Stringer

16. Структура `Money` (`Amount` float64, `Currency` string) реализует `String() string`, возвращающий что-то вроде "150.00 USD". Создай срез из нескольких `Money` с разной валютой и выведи их через `fmt.Println` по одному.

17. Структура `Task` (`Title` string, `Done` bool) реализует `String() string`: для выполненной задачи — "[x] Название", для невыполненной — "[ ] Название". Собери срез из 5-6 задач в разном состоянии и выведи список одним циклом через `fmt.Println`.

io.Writer

18. Напиши функцию `LogMessage(w io.Writer, msg string)`, которая пишет `msg` в `w` через `fmt.Fprintln`. Вызови её дважды: один раз с `os.Stdout` (сообщение уйдёт в консоль), второй раз — с `&strings.Builder{}`, сохранив результат в переменную, и выведи содержимое билдера через `fmt.Println`.

Задачи среднего уровня

19. Опиши интерфейс `Handler` с методом `Handle(event any)`. Заведи `map[string][]Handler` — подписчики по имени события, и две функции: `Subscribe` добавляет обработчик в карту по имени события, `Publish` вызывает `Handle` у всех подписчиков этого события. Реализуй два разных типа-обработчика (например, один просто печатает событие, у другого есть приватный счётчик вызовов). Подпишись обоими на одно событие и продемонстрируй `Publish` с разными данными в `event`.

20. Дан срез `[]Shape` из фигур `Circle`, `Rectangle` и `Triangle` (задача 2). Найди фигуру с максимальной площадью обычным циклом, без сортировки. После этого приведи найденную фигуру к конкретному типу и выведи дополнительные детали в зависимости от того, какая это фигура: для `Circle` — радиус, для `Rectangle` — ширину и высоту, для `Triangle` — все три стороны.

21. Опиши интерфейс `Command` с методом `Execute() (string, error)`. Реализуй несколько команд-структур, например одну, которая просто возвращает текст, и другую, которая делит два числа и возвращает ошибку при делении на 0. Собери `map[string]Command` — реестр команд по имени. В main() пройдись по срезу имён команд: для каждого имени найди команду в карте через comma-ok (имени может не быть в карте), вызови `Execute()` и выведи либо результат, либо ошибку.

22. По мотивам структуры `Category` (`Name` string, `Sub []Category`) из темы структур напиши функцию `PrintTree(v any, depth int)`, которая через `switch x := v.(type)` обрабатывает случай `Category` — печатает имя с отступом, зависящим от `depth`, и рекурсивно вызывает себя для `x.Sub`, и случай `[]Category` — рекурсивно вызывает себя для каждого элемента среза с тем же `depth`. Собери дерево категорий в 3 уровня и выведи его вызовом `PrintTree(rootCategory, 0)`.

23. Структура `Invoice` (`Client` string, `Amount` float64) реализует `String() string` вида "Client: 1500.00". Напиши функцию `WriteReport(w io.Writer, invoices []Invoice) float64`, которая для каждого счёта пишет его `String()` через `fmt.Fprintln`, а возвращает общую сумму по всем счетам. Вызови функцию один раз с `os.Stdout`, второй раз с `&strings.Builder{}`, и в обоих случаях выведи возвращённую сумму.

24. Опиши структуру `ValidationError` (`Field` string, `Message` string) с методом `Error() string` (тем самым она реализует встроенный интерфейс `error`) вида "поле Field: Message". Функция `ValidateAge(age int) error` возвращает `&ValidationError{...}`, если возраст отрицательный или больше 130, иначе `nil`. В main() вызови функцию на нескольких значениях возраста; если пришла ошибка — приведи её к `*ValidationError` с `, ok`, достань поле `Field` отдельно и выведи его вместе с текстом ошибки.

Что считается сделанным: интерфейсы реализуются неявно (нигде не пишется "implements"); там, где приведение типа может не сработать, используется безопасная форма с `, ok`, а не паникующая `v.(T)`; в задачах на Stringer вывод идёт через `fmt.Println`/`fmt.Printf` с `%v`, без ручного вызова `String()`.
