1. Объяви массив целых чисел размером 5, заполни любыми значениями. Выведи сам массив и его len.
2. На основе массива из задачи 1 сделай срез, взяв несколько элементов из середины (например, со 2-го по 4-й). Выведи получившийся срез, а также его len и cap.
3.Заведи срез из 5–6 чисел на своё усмотрение. Через for пройдись по нему и посчитай сумму всех элементов. Выведи результат.
4. Создай пустой срез строк. Добавь в него через append три любых слова по очереди, после каждого добавления выводи срез и его len.
5. Дан срез из нескольких чисел. Через цикл умножь каждый элемент на 2 прямо в этом же срезе и выведи результат.
6. Дан срез чисел. С помощью цикла и if найди максимальный элемент и выведи его.
7. Дан срез из нескольких чисел. Через цикл выведи его элементы в обратном порядке (не создавая новый срез, просто печатью).
8. Создай пустой срез с небольшой начальной ёмкостью. В цикле добавляй в него числа через append и на каждой итерации печатай len и cap. Посмотри, когда и как меняется cap.
9. Дан срез чисел. Через цикл и if (или switch) посчитай отдельно количество чётных и нечётных элементов.
