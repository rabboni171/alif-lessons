# Урок 19 — select, таймауты и context

Шпаргалка для лайв-кодинга. Полная теория, тайминг и ДЗ — в `Urok_18_Select_i_sinhronizaciya.md`.

## Главные аналогии (сказать в начале)
- `select` — **диспетчер на нескольких телефонах**: сидит человек перед пятью аппаратами, ждёт, какой зазвонит первым, берёт трубку именно у него. Звонят два сразу — выбирает случайно.
- `context` — **пульт отмены**: запустил задачу и держишь кнопку «стоп». Нажал — все, кто слушает этот пульт, останавливаются.

## Частые ошибки новичков
| Ошибка | Симптом | Решение |
|---|---|---|
| Все каналы пусты, нет default/timeout | deadlock | Добавить `default` или таймаут |
| `default` без паузы в вечном цикле | 100% CPU | Убрать `default` или добавить `time.Sleep` |
| Забыт `cancel()` | Утечка контекста | `defer cancel()` |
| `time.Tick` вместо `NewTicker` | Утечка тикера | `defer ticker.Stop()` |
| Нет проверки `ok` при чтении из канала | Бесконечные нули | `v, ok := <-ch` |
| `ctx` не первый параметр функции | Нарушение соглашения | `func f(ctx context.Context, ...)` |
