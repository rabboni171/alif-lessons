# Урок 18 — Каналы (channels)

Шпаргалка для лайв-кодинга. Полная теория, тайминг и ДЗ — в `Urok_17_Kanaly.md`.

## Главные аналогии (сказать в начале)
- Канал — **труба между горутинами**. Одна кладёт в один конец, другая забирает с другого.
- **Небуферизированный** канал — передача из рук в руки: отдающий стоит с протянутой рукой, пока кто-то не возьмёт (это и синхронизация тоже).
- **Буферизированный** канал — почтовый ящик на N писем: кладёшь и уходишь, пока ящик не полон.
- Девиз Go: «Не общайтесь через общую память — разделяйте память через общение».
- Правило: если задача про **передачу** данных — канал; если про **защиту** общего состояния — мьютекс.

## Частые ошибки новичков
| Ошибка | Симптом | Решение |
|---|---|---|
| Отправка без получателя | deadlock | Запустить горутину |
| `range` без `close` | Зависание | Закрывать у отправителя |
| Отправка в закрытый канал | panic: send on closed channel | Закрывать после всех отправок |
| Двойной `close` | panic | Закрывать один раз |
| Получатель закрывает канал | Паника у отправителя | Закрывает только отправитель |
| `nil`-канал | Вечная блокировка | Создавать через `make(chan T)` |
