Задание 1. Все основные типы данных Объявите переменные следующих типов
данных: - int - int8 - int16 - int32 - int64 - uint - uint8 - uint16 -
uint32 - uint64 - float32 - float64 - bool - rune - byte - string -
complex64 - complex128

Не присваивая значения, выведите их на экран и узнайте значения по
умолчанию. После этого присвойте каждой переменной осмысленное значение
и снова выведите их.

Задание 2. Арифметические операции Объявите две переменные типа int.

Выполните следующие операции: - сложение - вычитание - умножение -
деление - остаток от деления

Выведите результат каждой операции.

Задание 3. Работа с константами Создайте константы: - PI - CompanyName -
CurrentYear - DaysInWeek

Выведите их значения.

Задание 4. Анкета пользователя С помощью fmt.Scan() запросите у
пользователя: - имя - возраст - рост - вес - работает ли он (bool)

После ввода красиво выведите всю информацию.

Задание 5. Мини-калькулятор Запросите у пользователя два целых числа.

Выведите: - сумму - разность - произведение - частное - остаток от
деления

Задание 6. Паспорт разработчика Создайте программу, которая хранит
информацию о разработчике.

Используйте как можно больше изученных типов данных.

Например: - имя - фамилия - возраст - стаж - зарплата - любимый язык
программирования - опыт коммерческой разработки - знает ли Docker -
первая буква имени (rune) - любимый ASCII-символ (byte) - количество
написанных проектов (uint)

Красиво выведите информацию через fmt.Printf().

Задание 7. Изменение значений переменных Создайте несколько переменных.

По ходу программы измените их значения минимум 3 раза.

После каждого изменения выводите текущее значение.

Задание 8 (со звездочкой) Напишите программу «Моя визитная карточка».

Используйте: - переменные - константы - fmt.Print - fmt.Println -
fmt.Printf - fmt.Scan - все основные типы данных

Программа должна запросить данные у пользователя и затем красиво вывести
их в виде небольшой анкеты или резюме.
