Домашнее задание: пакеты (import, свои пакеты), функция init()

Свои пакеты внутри одного модуля

1. В той же папке заведи пакет `geometry` с функциями `RectangleArea(width, height float64) float64` и `RectanglePerimeter(width, height float64) float64`. В `main.go` вызови обе функции для двух-трёх прямоугольников с разными сторонами и выведи площадь и периметр каждого.

2. Заведи пакет `strutil` с функциями `Reverse(s string) string` (разворачивает строку) и `IsPalindrome(s string) bool` (использует `Reverse` внутри себя). В main проверь несколько слов и фраз, выведи для каждой, палиндром она или нет.

3. Заведи пакет `validator` с функциями `IsValidEmail(email string) bool` (проверка на наличие "@" и хотя бы одного символа после точки в домене — простыми strings-функциями, без regexp) и `IsAdult(age int) bool`. В main проверь несколько пользователей (email + возраст) и выведи, кто из них прошёл обе проверки.

Отдельный модуль: go mod init, свои пакеты и main

4. Создай новую папку `taskmanager`, зайди в неё и выполни `go mod init taskmanager`. Внутри заведи пакет `task` со структурой `Task` (`Title` string, `Done` bool) и функцией-конструктором `New(title string) Task`. В `main.go` создай через `task.New` три-четыре задачи, отметь часть из них выполненными и выведи список с пометкой `[x]`/`[ ]` перед названием.

5. Создай папку `shop`, выполни `go mod init shop`. Заведи пакет `catalog` со структурой `Product` (`Name` string, `Price` float64) и функцией `TotalPrice(products []Product) float64`. В `main.go` собери срез из нескольких товаров и выведи их общую стоимость.

6. Создай папку `library`, выполни `go mod init library`. Заведи пакет `book` со структурой `Book` (`Title`, `Author` string, `Year` int) и пакет `catalog`, который импортирует `book` и содержит функцию `FindByAuthor(books []book.Book, author string) []book.Book`. В `main.go` собери срез книг разных авторов и выведи результат поиска по одному из них — так один свой пакет использует другой свой пакет внутри того же модуля.

Функция init()

7. Заведи package-level переменную `AppName string` без значения и функцию `init()`, которая присваивает ей значение по умолчанию, например "MyApp v1.0". В `main.go`, ничего не присваивая переменной вручную, выведи `AppName` — значение должно быть уже готово к моменту запуска main.

8. В одном пакете объяви подряд две функции `init()` (в одном файле или в разных файлах пакета) — в каждой выведи через `fmt.Println`, что она выполняется, и по какому имени/номеру. Запусти программу и по выводу проверь, в каком порядке Go вызывает несколько `init()` одного пакета; результат объясни комментарием прямо в коде.

Внешние зависимости: go get

9. Выполни `go get github.com/google/uuid`. Заведи структуру `User` (`ID`, `Name` string) и функцию `NewUser(name string) User`, которая создаёт `ID` через `uuid.NewString()`. В main создай несколько пользователей с разными именами и выведи каждого — убедись, что ID у всех разные.

10. Выполни `go get github.com/fatih/color`. Напиши функцию `PrintCheck(name string, passed bool)`, которая зелёным цветом (`color.Green`) печатает "OK: name", если `passed == true`, и красным (`color.Red`) — "FAIL: name" в противном случае. Вызови функцию для нескольких проверок с разным результатом (например, результаты каких-нибудь тестов) и убедись, что цвет в терминале действительно меняется.

Задачи среднего уровня

11. Создай папку `store`, выполни `go mod init store`. В пакете `catalog` заведи структуру `Item` (`Name` string, `Price` float64, `Stock` int), package-level переменную `Items []Item` и `init()`, который заполняет `Items` стартовым набором из 4-5 товаров (имитация "предзагруженного каталога"). Заведи второй пакет `report`, который импортирует `catalog` и содержит функцию `TotalValue(items []catalog.Item) float64`, считающую сумму `Price * Stock` по всем товарам. В `main.go` вызови `report.TotalValue(catalog.Items)` и выведи результат.

12. Заведи пакет `registry` с интерфейсом `Handler` (метод `Handle(text string) string`), package-level `map[string]Handler` и функцией `Register(name string, h Handler)`, добавляющей значение в карту. Заведи два отдельных пакета, например `upper` и `reverse`, каждый со своим типом, реализующим `Handler`, и функцией `init()`, которая регистрирует этот тип в `registry` через `registry.Register(...)`. В `main.go` заимпортируй оба пакета (даже если явно их функции не вызываешь — импорта достаточно, чтобы выполнился их `init()`), перебери зарегистрированные обработчики по имени и вызови `Handle` у каждого с одной и той же строкой.

13. Создай папку `session`, выполни `go mod init session` и `go get github.com/google/uuid`. Заведи пакет `tracker` с package-level переменной `StartedAt time.Time` и `init()`, который присваивает ей `time.Now()` (имитация времени запуска приложения), а также функцией `NewSessionID() string`, возвращающей `uuid.NewString()`. В `main.go` создай три "сессии" (ID + `tracker.StartedAt`, которое у всех одно и то же, потому что выставлено один раз в init()) и выведи их.

14. Создай папку `config-demo`, выполни `go mod init config-demo`. Заведи пакет `env` с функцией `init()`, которая проверяет переменную окружения `APP_ENV` через `os.Getenv("APP_ENV")` и паникует с понятным сообщением, если она пустая. Убедись на практике: запусти программу без переменной окружения (получишь panic ещё до входа в main) и запусти с ней, например `APP_ENV=dev go run .` (программа должна нормально стартовать и напечатать значение `APP_ENV` из main).

Ещё практика: экспорт, алиасы, несколько файлов, циклы и документация

Что считается сделанным: для каждой задачи с отдельным модулем действительно создана своя папка со своим `go.mod` (через `go mod init`), а не всё сложено в один уже существующий модуль; импорт всегда идёт по module-path из go.mod (например `taskmanager/task`), а не по относительному пути; в задачах 9, 10 и 13 зависимость реально подтянута через `go get` и видна в `go.mod`/`go.sum`; в задачах на init() ничего из того, что делает init(), не продублировано вручную в main(); в задаче 15 доступ к `balance` идёт только через методы, а не напрямую к полю; в задаче 19 сначала действительно получена ошибка `import cycle not allowed`, а не просто написан код без цикла.
